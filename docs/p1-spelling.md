# P1答案词拼写冲刺

160词，8组，每组20词。前4组80词是核心，后4组为扩展。打开Wordly首页“老师布置的单词任务”，选择2026-11-23。先学词表→检测本组→错词复测。11/24另有4组独立隔日盲测，首次成绩与修正记录分开。

词表当前全词最新拼写正确才显示本批完成；严格任务关闭自评通过，接受明确的常用英美拼写变体。学习浏览不记成绩。词表为P1常见场景整理，非官方频率排名或押题。

整段目标：连续3篇完全陌生P1，原速一次不暂停，每篇至少9/10，且无拼写失分。未达到则只针对实际错因补练，不重复整本词库。

每天先20-30分钟词表，10分钟错词；练一篇陌生P1约10分钟，核对5分钟。隔日盲测先不看词表。

语音：160词均有内置Kokoro词音，补充了原来缺失的50词。首次答案、日志、录音和旧词库保持原存储位置。
