# 口语结构练习

入口：口语首页 → **口语结构练习**，也可打开原站点的 `#speaking-structure`。

本入口按回答任务组织 Part 1，与原来的题库、口语素材、录音训练和口语词汇转换记忆分别保留。

## 题库与训练

- 读取原题库335问，加90条讲义中的通用练习问句，合并为425道不同题干。只打包题干和来源名称，不打包私人故事、答案、课堂反馈、原PDF/Word或本地路径。
- 分为喜好/感受、选择/比较、频率、具体信息、方法/行动、原因/判断、过去经历、今昔变化、未来假设九组。
- 每组一轮最多20道不同题，先跨话题轮换；不足20题显示实际题数。完整库始终保留。
- 喜好组先选喜欢、不喜欢、具体偏好、感受或能力子组；过去组固定童年、已有经历、具体过去或过去原因，再练相同时间线。
- 中英框架折叠显示，按子类提供不同起手式。三四句作为训练支架，实际可按问题调整。

## 怎么编辑

1. 点击“查看与编辑完整库”，搜索题干或话题。
2. 点击题目，在“编辑题干与分类”中修改自己的显示版本；原题仍保留。
3. 在练习页记录自己的原话、修正后的表达和错误；输入自动保存。
4. 框架中的“我的框架补充”用于持续调整同类回答方式。
5. 点击“保存本次练习”或“标记需要再练”，单独留下本次回答；第一次提交保持，后续练习追加历史。“已练过”是自报记录，不等于自动评分或达标。

## 存储、备份和接续聊天

数据在原键 `wordly_app_v1` 的 `speaking.structures` 内；录音继续使用 `wordly_audio_v1`。不清理或替换旧词汇、题卡、听写、口语草稿、课堂整理和录音。

完整备份包含题库、框架、草稿、首次回答、复测历史和续练位置。重复导入按题干稳定ID合并；原站点设置里的完整学习备份也保留本模块。跨标签保存合并独立记录。

“导出这组复盘”生成小范围Markdown，包含本轮题目、原话、修正和错误，供之后聊天读取。它让后续助手能恢复实际进度；助手不会自动读取浏览器中尚未导出的记录。切换设备或浏览器前应导出；JSON学习备份不包含录音。

## 考频依据

[IDP 的 Part 1 常见话题说明](https://ielts.idp.com/nepal/prepare/speaking/part-1-topics-and-questions)列举工作学习、家乡住所、日常生活、兴趣等常见范围。该页面没有各题型的考场次数和样本量。

因此界面显示“常见话题优先”的定性依据，类内跨话题轮换；不把题库条数当作考试频率，也不显示未经证实的命中率。未来导入实测考频时，记录须含次数、样本量、时间范围、地区和来源链接。

## 维护与验证

- 主模块：`assets/speaking-structure.js`；样式：`assets/speaking-structure.css`；通用补充题：`assets/speaking-structure-questions.js`。
- 在原数据库增量规范化 `speaking.structures`，保存失败回滚，原记录读取失败时停止写入。
- 修改后运行 `node scripts/version-speaking-library.mjs`、`node scripts/version-study-library.mjs`、`node --test tests/*.test.cjs` 和 `node scripts/build-github-pages.mjs`。
- DOM模拟验证不等于真实浏览器麦克风或跨设备同步验证。
