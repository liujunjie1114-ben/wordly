# 口语词汇转换记忆

入口：`#speaking-vocab`，也可从口语首页或口语整理库进入。

内置120条通用口语表达，10个场景，每个场景覆盖基础自然、常用拓展和中等进阶。每项有中文提示、主要表达、合理替换、示例、卡住时的简单接法与用法提醒。例句不是用户私人经历。

练习按场景、程度和数量筛选，使用Fisher-Yates乱序。揭晓前隐藏英文，允许口头回答或可选打字；打字只核对已列表达及基础标点、空白、大小写，不声称理解所有同义答案。口头结果由用户自评，不做自动语音评分。计时是启动参考，没有超时扣分。

原学习键仍为 `wordly_app_v1`，状态放在 `speaking.drafts['vocab-recall-v1']`：独立命名空间内保留逐次attempts和当前round draft，不占用旧题卡草稿。保存先重读其他标签的更新、合并按ID去重的历史，再通过原save写入；旧词库、错词、录音及其他草稿不变。刷新恢复当前题和已保存的揭晓状态。输入在切换页面及beforeunload时保存，写入失败会保留当前练习界面并提示，不将其当作已计分。完整学习备份包含该字段；普通资料包不包含练习进度。

卡词复测只选最新自评为卡住或没想起的词；当轮复测使用该轮结果。新轮不覆盖旧答案。数据文件使用稳定ID，新增内容应追加，不能重排已有ID。更新资料或交互后运行口语与资料模块版本脚本，再执行完整测试与GitHub Pages构建。

- `assets/speaking-vocab.css`：沿用原Wordly颜色与排版的响应式样式。

- `tests/storage-preservation.test.cjs`：原键、跨标签更新、备份恢复与旧进度保留。
