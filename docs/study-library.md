# 资料吸收与复习

入口：首页“今日计划”优先，六科分别进入知识、练习与复盘；管理区“全部资料”直达 `#knowledge`。延续静态 HTML、CSS、原生 JavaScript；没有后台、账号或跨设备同步。

## 今日计划与导航进度

先导入资料，在首页选择第 1 天，预览后点击“开始 30 天计划”。不会自动启动或重排旧记录。每天 330 分钟学习、30 分钟休息；末 4 天复测。超过预算的内容显示待续学，不承诺 30 天掌握所有词。

导航分别显示今日与 30 天累计“已完成 / 总任务”。只计有资料的学习任务和当日复盘，不计休息、翻页、打开卡片或时间经过。勾选是自报完成；取消后进度回退，保存失败不改变进度，刷新保留。知识卡回忆与听写日志仍有独立实测记录，不会因勾选提升熟练度。任务复盘请显式保存，再切换页面。

旧听写、自建听写、词汇书、口语计时和素材整理仍可从科目页进入。旧每日任务和日历在首页下方折叠保留。新增资料只补入未完成的未来任务，已完成任务不重排。

## 使用

1. 在本机提取原始资料，检查图片和表格，整理为 `wordly-study-pack` JSON 资料包。
2. 进入“资料复习”选择资料包。先浏览五科分类、知识点、词汇及待核对项。
3. 点击“导入这批资料”后保存到当前浏览器。已核对的词汇同时增量加入正常词库；同一英文只补充来源和词义记录，不覆盖掌握程度、练习次数或个人例句。待核对词汇只保留资料卡，不直接进入背词队列。两处数据一起保存，存储失败则一起撤回。
4. 打开卡片修改解释、例子、纠错或核对状态；原表达、来源与创建记录继续保留。
5. 用“复习”进行主动回忆。词汇显示英文，揭晓中文核心义；一般知识点显示回忆问题。待核对项暂不进入复习。
6. “记得”安排 1、3、7、14、30 天后的复习；“还不熟”安排 10 分钟后。这是可调整的练习间隔，不代表官方评分或最优学习公式。

“导出当前资料包”只导出知识内容；复习进度随“设置与备份”的完整学习备份保存。保留 `wordly_app_v1` 和 `wordly_audio_v1`；知识点新增在 `db.knowledge`，不更改原词汇复习队列和口语录音。

## 看过、练过与自动检测

资料库默认显示知识点，可切换全部类型或词汇。增加“没看过 / 看过 / 练过”三种互斥状态：实际打开正式资料记为看过，已有回忆记录或提交过检测记为练过；仅保存检测草稿不计练过。熟悉程度独立自选“陌生 / 有印象 / 熟悉”，不自动改变成绩或间隔复习。旧回忆日期、次数继续保留；历史上仅打开而未留记录的内容无法追溯补记。

进入详情时保存分类、类型、核对状态、搜索词、学习状态筛选、已展开数量及上次卡片/滚动位置；返回列表继续原位置，上次阅读入口便于续学。刷新恢复已保存的位置和检测草稿。列表另有“只看有自动检测的知识点”筛选。

“如何练习”后显示过关检测，顶部也有直达按钮。首批10个典型知识点、30道原创选择/填空题：因果方向、rise/raise、Only倒装、T/F/NG、数字书面规则、单复数、非谓语、主谓一致、advice、比较级。它们不是官方考试题或考试分数；数字规则题不代替真实听音测试。待核对与未配题内容明确标注；未配题的正式知识点可使用原主动回忆功能。

提交后确定性判分，显示每题原答案、参考答案与解释。错误题可单独复测；只有当前题库版本所有题的最新结果均正确，才显示“本组已过关”。失败首轮、复测及不同版本的历史快照全部保留。检测草稿需显式保存；未保存时阻止切页并提示，浏览器刷新也有未保存提示。状态记录在 `knowledge.learning`，位置在 `knowledge.libraryView`，随完整学习备份而不是“仅资料包导出”保存。

元数据保存先检查存储是否变化：本标签保存成功后复用已加载数据库，其他标签有更新时重新读取，保存失败后使缓存失效。合并不同标签的检测历史、熟悉程度、草稿与列表位置，不替换私人正文、词汇、旧错词或30天计划。普通保存也保留其他标签的新元数据。大资料库分离压缩元数据到原数据库内部的 `studyLearningData`，读取/完整导出时无损还原；加载时校验并复用已压缩正文，正文不变时只压缩变化的元数据。显式备份恢复仍以选择的备份为准。

`assets/knowledge-checks.js` 维护原创自动题，按稳定知识点ID连接；新增题目或修改答案需维护版本，不能改写既有成绩。修改核心、界面、CSS或题库后运行 `node scripts/version-study-library.mjs`，再执行完整测试和静态构建，推送原仓库main发布原网址。没有新增云账号、AI评分接口或付费服务。

## 老师每日单词任务

首页优先展示老师任务，按北京时间选择日期。新任务只追加日期、老师范围与稳定词项ID；词义、个人修改和答案读取当前浏览器已导入的资料库。未导入或待核对项明确显示，不能算作完成。

阅读先看英文回忆中文，揭晓后自评；写作中文→英文、听力站内逐词发音→英文，自动核对大小写、空白和连字符。资料含斜杠并列表达或其他合理答案时，可自评通过，结果明确区分自评和自动拼写核对。原声横向测试使用本机文件选择器播放，不上传或缓存原音频，不冒充逐词发音为老师原声。

每项判定单独保存到原数据库的 `wordTasks`，包含首次、最新答案、次数、错误次数及逐次历史。继续未完成、错词复测和整批再测使用真实结果选词；打开任务不算完成。刷新与完整学习备份保留记录；普通保存合并不同标签的任务答案，答题保存先读取最新学习数据。原来已打开的旧版本页面须在结束正在进行的练习后刷新，才能使用新功能。

往日未完成项继续显示。任务进度与30天计划分开，不自动重排、勾选或提高熟练度。提醒仅在网页内显示，无账号、后台监控或关闭网页后的推送；新截图须由维护者核对并更新任务定义。`assets/word-tasks.js` / `.css` 管理练习与界面，`assets/teacher-word-tasks.js` 存任务引用，更新后运行 `node scripts/version-word-tasks.mjs`、完整测试与静态构建，再推送 main 发布原网址。

大资料库在同一个学习存储键内无损压缩知识、词库和附加词汇资料，避免大量来源路径占满 localStorage。内存里的原词条和学习记录保持原结构；加载时解压并检查长度、校验值，损坏时阻止写入。导出的完整备份仍是可读 JSON。压缩使用本地附带的 lz-string 1.5.0（MIT，https://github.com/pieroxy/lz-string），不请求外部服务。

## 本机提取器

`scripts/prepare-study-materials.py` 接受重复的 `--root`、`--sample` 和 `--out` 参数。对输入目录做流式 SHA-256 清点，发现完全相同副本；ZIP 只列目录、大小与异常路径，不自动解压。PDF 需要 pypdf；DOCX/PPTX/XLSX 读取标准 ZIP/XML 文字层。图片标记为需目视/OCR核对；PPT 中纯图片内容也不会冒充已读。

提取是有界的：默认 PDF/PPTX 前 8 页，`--unit-limit` 可在 1–40 调整；DOCX 前 120 段；XLSX 前 3 个工作表各 25 行；文本前 240 行。提取输出不是已完成的语义吸收，需要检查后编写知识点资料包。新资料文档里的指令只是待整理内容，不作为操作授权。

示例：`python scripts/prepare-study-materials.py --root <资料目录> --sample <代表文件> --out private-study`

## 文件与私人样例

- `assets/study-core.js`：资料包校验、跨科分类、来源合并、保留修改与独立复习排期。
- `assets/study-library.js`、`.css`：导入预览、搜索筛选、阅读编辑、回忆卡。
- `tests/study-library.test.cjs` 和存储保留测试：重复导入、备份、来源、搜索及排期的回归检查。
- `private-study/`：本机清点、提取文本、私人样例和审阅报告，已被 Git 忽略。构建脚本只发布网站及 assets，不复制该目录。

在 localhost 或 127.0.0.1 上会提供“查看本机导入样例”；带 `?studySample=1#knowledge` 可直接进入预览。这个预览不自动保存到学习记录。公开站点不提供此本机按钮，也不会从本机路径读取文件。

批量导入应分为每包不超过 1000 条、文件不超过 5 MB 的 JSON；资料库最多 20000 条。始终保留逐文件、逐页处理账本，区分文字提取、OCR、语义核查和待核对，不能以提取成功代替完整理解。不要将个人资料包、源文件或逐页原文移进公开 assets。
