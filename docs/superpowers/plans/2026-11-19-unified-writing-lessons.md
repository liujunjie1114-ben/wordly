# 统一 Wordly 写作课程

**Goal:** 在原 GitHub Pages Wordly 内统一原 19 节课和 11 月 18 日互动课堂，用户无需跳转到另一个网站。

**Architecture:** 沿用原生静态结构和 `wordly_app_v1`。课程段落可增加受信任的互动课类型；私人课堂 HTML 随完整课程包/学习备份保存在浏览器，不公开到 Git。互动课在无同源权限的 iframe 中运行，内容须匹配已审查的 SHA-256，进度通过校验后的消息保存回原库。

**Spec:** 用户本次明确要求所有课程放进 Wordly，且原有训练方法、资料、写作记录必须保留。
