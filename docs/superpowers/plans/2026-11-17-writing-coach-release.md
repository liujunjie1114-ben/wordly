# Wordly 写作教练发布计划

**Goal:** 把现有写作教练作为 Wordly 内部模块发布到原 GitHub Pages，保留训练方法、资料与学习记录。

**Architecture:** 沿用静态 HTML、CSS、原生 JavaScript。复用本地已有教练模块；正文位于 `wordly_app_v1.writingCoach`，配套资料沿用 `knowledge`。私人课程通过完整教练包导入浏览器，不加入公共 Git 仓库。

**Spec:** 用户本次整合请求及仓库 `AGENTS.md`。

## 约束与实施选择

- 保留 `wordly_app_v1`、`wordly_audio_v1` 与现有网址。
- 不清空存储，不覆盖私人写作、原始答案或录音。
- 原工作区有未提交修改及缺失 PDF；在最新 `origin/main` 的独立工作树准备发布，不重置原工作区。
- 复用已有内部页面；本机链接无法完成线上整合，公开嵌入私人课程违反仓库约定，因此线上使用课程包导入。

## 核心检查

- 无正文的旧备份继续读取；非法课程包和存储写入失败不会覆盖原状态。
- 同内容资料使用保留的原 ID，不产生重复副本。
- 旧标签页保存保留最新课程及其资料、用户编辑和复习日期。
- 导入 HTML 过滤脚本、事件属性及不安全链接。
- GitHub Pages 使用 `/wordly/` 下相对资源；本机私人端点不进入公共产物。

## 审查与修复

- 独立代码审查发现：跨标签保存时无条件采用已存卡会撤销当前新编辑。采用读取基线三方合并，双方同卡冲突时停止覆盖；新增回归先失败再通过。
- 延迟文件读取后换页会误用共用容器。增加教练专用容器存活校验，浏览器回归验证换页后不继续导入。
- 本机自动读取与文件选择相遇时，文件导入等待本机读取完成，避免丢弃文件选择。
- 手机次级导航隐藏，因此在写作主页增加教练入口，并通过实际点击验证。
- 最终本地验证：201 项 Node 测试通过；静态构建成功；隔离 Edge 全流程通过、无页面错误。线上发布证据在本次交付报告中记录。
