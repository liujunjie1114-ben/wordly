# Wordly 逐卡复盘实施计划

**Goal:** 将现有知识卡、词汇卡和自动检测复盘统一为截图所示的题号导航、左侧原资料、右侧答案依据。

**Architecture:** 静态 HTML 与原生 JS 不变。新增只读展示模块，从当前浏览器的条目字段构建逐卡解析，不迁移或重写正文和学习状态。原有主动回忆、自评、检测、编辑、导入和备份接口继续使用。

**Scope:** 用户明确选择直接修改 Wordly 网站。默认卡片详情替换为对照页；自动检测结果逐题复盘；主动回忆揭晓后展示同一结构。保持原 GitHub Pages / Vercel 网址。

## 约束与选择

- 对比方案：仅换 CSS 无法分清原文与讲解；把私人正文生成静态网页会公开个人内容。采用运行时只读展示。
- 真实 original 才称原文；缺失时使用 explanation / example，明确标注整理笔记。
- 不生成未经依据的标准答案或个人经历。缺失的例句、辨析、练习明确保留空缺提示。
- 原 stable ID、检测版本、首次作答、历次成绩、熟悉程度、复习时间和存储键全部保留。
- 大库导航最多显示当前附近 16 张卡，不为 12,886 张卡一次建立完整 DOM。
- 有草稿时切换仍经 beforeNavigate；主动回忆揭晓前两栏均不泄露答案。
