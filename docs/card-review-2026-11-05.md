# Wordly 按科目、按题型滚动练习

入口：Wordly 左侧「题型闯关」，地址保持原站并增加 `#trainer`。本科页的「做练习」和「全部资料」也可进入。

1. 选择听力、阅读、写作、口语、语法或词汇，再按题型选组。每组最多 16 张；题型由卡片标题、标签和适用场景依次确定，不能确定的归入「综合方法」。
2. 在完整题面中独立回答。可保存整组草稿；回答尚未保存时会阻止离开。
3. 保存回答后逐题对照：左侧原文／整理笔记，右侧结论、解释、例子、适用场景、易错点和再练一步。
4. 每张卡连续两次独立作答后自评「记得」算自评达标；任何一次「还不熟」重新累计。结束后可继续薄弱卡、整组再测或下一组。
5. 首次回答、逐次自评和草稿随原完整备份保存。自评达标与原有自动检测的成绩、熟悉程度、间隔复习分开，不能互相冒充。修改题干或参考结论后，旧记录继续保留，但需重新累计自评达标。

待核对卡片不参加闯关；未附原文时标为「整理笔记」，不生成假原文或假标准答案。自动检测仍使用原题目 ID 与版本，复盘分别展示首次和最近答案。

## 改动文件

- `assets/type-trainer.js`：科目／题型分组、整组题面、草稿、自评、薄弱重练与下一组。
- `assets/card-review.js`：所有知识／词汇卡的只读对照解析、题号导航与检测逐题复盘。
- `assets/study-core.js`：在原 `knowledge.learning` 中增加可选 `recallAttempts`、`recallDraft`、`recallDraftUpdated`，校验、跨页合并及完整备份保留新旧记录。
- `assets/study-library.js`、`.css`：接入双栏详情、主动回忆与训练页面，窄屏单栏显示。
- `assets/study-dashboard.js`、`index.html`：原站侧栏与科目练习入口。
- `scripts/version-study-library.mjs`：刷新模块缓存版本。
- `scripts/audit-card-review.cjs`：逐条检查本机备份字段覆盖；私有报告仅写 `private-study/`，不进入公开网站。
- `tests/card-review.test.cjs`、`tests/type-trainer.test.cjs`、`tests/storage-preservation.test.cjs`：覆盖来源区分、遮答案、分组、成绩隔离、首次答案与新旧备份兼容。
