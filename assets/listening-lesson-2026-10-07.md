## 一、这次课的核心

**从“听到某个单词就选答案”，转向“听清词形、判断信息归属、核对完整关系”。**

| 学习模块 | 本次重点 | 应达到的动作 |
|---|---|---|
| 辨音与拼写 | M/N、字母串、复数词尾 | 不依赖提示辨认；检查答案的单复数 |
| 填空题 | 字数限制、标题、词性、定位、同义替换 | 听前知道缺什么；听后检查格式 |
| 信息前置 | 答案可能早于题干中的定位信息出现 | 听到相关候选词先短记，继续核验 |
| 地图题 | 起点、地标、方位、序数及信息归属 | 用“参照地标＋空间关系”定位 |
| 跟题与恢复 | 换话题、漏题后的重新定位 | 漏一题后及时跟进下一题 |

老师在纪要中指出的具体问题：部分题目抓到单词但没有理解评价对象；复数词尾容易遗漏；地图题预设顺时针或自下而上路线，导致跟丢；一题漏听后影响后续；词汇听辨不足。纪要没有完整得分，不能据此给听力水平定级。

## 二、辨音：字母与词尾必须分开练

### 1. M与N

- 字母名：M /em/，N /en/；二者末尾鼻音不同。
- /m/：双唇闭合，气流经鼻腔。
- /n/：舌尖接触上齿龈，气流也经鼻腔。不能记成“M闭嘴，N只是出气流”。
- mother与no可帮助体会两种辅音，但字母串听写仍要直接练字母名。

纪要把aim与an作了不准确的音标对照：aim是/eɪm/；an通常弱读/ən/，强调时可读/æn/，不是/eɪn/。aim也不等于字母M。姓名拼写A.M.D.H.A.N.I.A仅为纪要记录，未对照录音确认。

**补充练法：**随机听10个M/N字母，先写再核对；第二轮换顺序，不能依靠背顺序。接着听实际字母串，记录是字母本身混淆还是连续拼写跟不上。

### 2. 复数词尾

老师要求做“只写听到的复数名词”的专项精听。目的在于提高词形敏感度，不能把正常做题也变成只听复数。

- 规则复数：注意-s/-es，如chairs、tables、areas。
- 不规则复数：如child→children；普通名词child的复数不是childs。
- 结合题干语法：many、several、both后通常使用复数可数名词；a/an后通常使用单数可数名词。
- 听到多个并列名词，不代表全部必须填入；答案取决于题干、空格数量与字数限制。

**专项步骤：**选1–2分钟材料→不看原文记复数名词→核对原文→标记漏词与漏词尾→关闭原文再听。不要只抄原文中的复数词。

## 三、填空题：按六步处理

| 步骤 | 具体操作 | 检查重点 |
|---|---|---|
| 1. 看限制 | ONE WORD ONLY或其他字数／数字要求 | 超出限制即使意思对也不符合要求 |
| 2. 看标题 | 确认课程、建筑导览、活动等主题 | 预测信息类型，不猜最终答案 |
| 3. 看空格 | 查看前后语法及已给单位 | 名词／形容词／数字；单复数；是否已有£或room |
| 4. 找定位 | 标记题目对象与区分信息 | 不只勾共有词，注意问的是地点、时间还是物品 |
| 5. 听与核验 | 接受同义表达，跟住转折与评价对象 | 信息是否真正回答题干 |
| 6. 查格式 | 拼写、单复数、字数、单位及重复 | 将答案放回完整句子读一遍 |

### 课堂例子应该记住的逻辑

| 例子 | 需要学会什么 | 核验状态 |
|---|---|---|
| start与begin，随后提及library | 不死等题干原词；听清从哪里开始画 | library为纪要记录，未对题页核验 |
| hostel评价一般，新家具评价excellent | “一般”与“很好”分别修饰不同对象，不能串用 | hostel/postal存在记录差异，词形待核对 |
| abandoned farm | 如果空格前已有a，关注符合该句的单数名词 | farm为纪要候选，不作为独立核验答案 |
| in the ___ century | 听清世纪并检查允许的书写格式 | 纪要记为18世纪，题页缺失，暂不指定最终格式 |
| many ___，涉及antique | many后需检查复数可数名词形式 | antiques为纪要记录 |
| 普通树木与rare ones | ones指代前文树木；ordinary与rare意义不同 | 保留区分逻辑，不推出未见题目的答案 |

**不能按选项分布猜答案。**“前面没选C，所以补一个C”没有依据。

### 同义替换要记含义，不能机械互换

| 表达 | 如何处理 |
|---|---|
| start / begin | 在表示开始的语境中常可对应 |
| first / initial | 分别表示首先／最初的；可能提示开始阶段，但词性与结构不同 |
| premiere | 常表示首演、首映，不能当成所有start的通用替换 |
| several / two or three | 某些语境可能对应少量几个；并非固定等价，one or two尤其不能一律等同于several |
| how many / how much | 分别询问可数数量／不可数量或金额，不等于a number of |
| a number of / varieties of | 分别涉及若干数量／多种类别；须判断题目考数量还是种类 |

## 四、信息前置：不要等定位词出现才开始听

本课所说的信息前置，适合这样理解：**录音中，答案信息可能出现在题干某个已知信息之前。**这不必是语法上的倒装或“主语前置”。

可执行方法：

1. 听前预测答案类别，如动物、房间、建筑或物品。
2. 听到相关候选词，短记关键词，继续听。
3. 用后续评价或限定关系确认，例如“哪个动物最受欢迎”。
4. 若随后出现否定、更正或让步，核对主体是否变化。

纪要中的swans与exotic animals例子：真正需要判断的是“哪类动物被说成最受欢迎”，不是听到animals就选。

**补充示例（为解释方法而写，非课堂原句）：**

> Swans remain the most popular, although the park has many exotic animals.

如果题目问最受欢迎的动物，swans先出现，most popular后确认。although补充另一面，但不会自动否定前面的主句。

原纪要对该例的语序描述前后不一致：18:34写让步从句后置；20:15又写先although后主句。因此这里只保留解题逻辑，不把任何一种顺序认定为真实录音。

also、and、recently、although等可以提醒留意结构，但并非每次出现都代表下一题。新名词也可能是例子或干扰信息，不能见新名词就填。

## 五、地图题：起点＋地标＋空间关系

### 听前准备

1. 看清题目要求：填地名、填字母还是选择选项。
2. 找you are here、入口、起点；路线题确认初始面向。
3. 有指北针时看清方向；没有时不要自行假定地图上方必为北。
4. 扫描已标地标：car park、main path、bookshelf、window、finish line等。
5. 分清题号与地图字母：题号是跟题依据；字母位置不必按顺时针或字母顺序出现。

### 听中定位

**目标地点＝参照地标＋方位／距离／先后关系。**

| 类型 | 例子 | 处理方式 |
|---|---|---|
| 单地标关系 | opposite the bank | 先找到bank，再处理opposite；不能只选离bank最近的位置 |
| 双地标关系 | between the car park and the main path | 同时满足两个地标之间的关系 |
| 路线指令 | turn left at the second turning | 跟住当前朝向，数到第二个路口再左转 |
| 方位先出现 | on your immediate left…随后说地点 | 先短记“紧邻左侧”，再确认目标名称 |
| 地点先出现 | the information centre…随后描述位置 | 锁定目标，再将后续位置关系挂到该目标上 |

老师所说的“就近信息”和“交叉信息”可以作为定位提示，但**地标与方位必须一起核对**。地标明确时，方位也不能忽略。

### 必记方位表

| 英文 | 含义／注意点 |
|---|---|
| on the left / on the right | 在左侧／右侧；看清参照对象 |
| on your left / on your right | 在你的左侧／右侧，依说话情境与面向判断 |
| right-hand side | 右侧 |
| turn left / turn right | 左转／右转 |
| opposite / directly opposite | 对面／正对面 |
| right opposite | 正好在对面；right在此强调位置，不是右侧 |
| right in the centre | 就在正中央；right不是右侧 |
| immediate left | 紧邻的左侧 |
| behind / in front of | 后面／前面 |
| between A and B | 在A与B之间 |
| next to / beside | 在旁边 |
| far side of | ……较远的一侧；不与directly opposite一律等同 |
| second turning | 第二个可转弯路口 |
| junction / intersection / crossroads | 交汇处／交叉路口；具体形状看图 |
| T-junction | 丁字路口；比纪要中的T road更规范 |
| entry / exit | 入口／出口 |

### 三组课堂地图例子

| 例子 | 课堂重点 | 本稿如何使用 |
|---|---|---|
| 图书馆／书架平面图 | centre、书架遮挡、immediate left；方位可先于地点出现 | 练习同时抓关系与目标，不能预设空间描述顺序 |
| high street、bank、house | 银行的opposite与房子的swimming pool关系不能串接 | 每换目标，更新“正在描述谁” |
| 欢乐跑赛事村 | 起点、finish line、information centre、餐饮区、领衫点、水站 | 分清入口出口与各功能点；使用多个关系确认位置 |

原纪要记录了C/E、I/H、information centre对应H等具体位置，但没有随附地图，**不在本稿中认定为已核验答案**。不同地图的字母不能混用。

corporate catering表示企业／公司餐饮服务，具体指地图上的何种设施以题页为准。shed tents／shade tents在纪要中存在可疑词形，需回听确认，暂不当成固定词组背诵。

### 漏题后的恢复

漏听→标记当前题→跟进下一题→抓明确目标名称或地标→重新核对空间关系。

不要在录音继续播放时反复回想上一题。练习时记录“从哪题掉线、靠什么重新接上”，而不仅记录最终选错哪个字母。

## 六、笔记中必须分清的错误与冲突

| 优先级 | 纪要问题 | 修正或处理 |
|---|---|---|
| Critical | “地图路线永远从下往上走”，后面又说不能预设自下而上 | 删除通用规则，按本题起点、朝向及录音路线判断 |
| Critical | “有地标时方位不重要” | 地标与空间关系共同决定位置，不能省略方位 |
| Critical | 死亡地点先记dining room，后记bird room | 具体答案暂不确认，需原题、原音或老师核对 |
| Critical | “空格在数量词后只能填名词，所以填several/both” | 结论自相矛盾；several/both本身不是该解释所需名词，必须查看空格位置 |
| Important | an音标误写；N描述不准确 | 按第二部分的辨音说明修正 |
| Important | child复数写成childs；并列名词一律全填 | child→children；是否填全部由题目和限制决定 |
| Important | “听力不会重复已给信息” | 录音可以重复；作答时不要重复填入题干已有成分或单位 |
| Important | 信息前置被混同为主语前置／让步从句后置 | 核心是答案与定位信息的先后关系，原句语序待核对 |
| Important | “严格按题号”“只有一道例外”混杂 | 跟题时按题号准备，不按空间顺序猜；不把未经核实的例外数量当考试规则 |
| Important | “回忆文本＋AI重录”被称为真题 | 按老师描述，将其视为回忆／改编练习材料；不能认定为官方原题原音 |
| Polish | 图书馆／巴顿大楼命名与个别词形可疑 | 例题建立材料名称、题号、原句记录，方便追溯 |

这些问题针对所提供纪要文字，不代表已核实老师在完整授课语境中的原话。
