IELTS SPEAKING ALL PRACTISED & LINKED STORY BANK 全量串题题库 · Part 1 / Part 2 / Part 3 · Codex Import Edition CORE RULE SHORT + CORRECT + CONTINUOUS. This is not a memorization book. It is a reusable story bank + correction database + import source. Compiled from the cumulative speaking notebook, final review, retained question bank, and the 2026-10-05 lesson.

练习状态与答题节奏

0. 使用说明与数据状态 STATUS LEGEND A = fully practised with stable user-specific answer. A2 = newly practised and still needs retakes. B = linked/practised but some wording/details are reconstructed from retained notes. C = scheduled/exposed topic without enough confirmed personal detail; Codex must not invent autobiography. PART1: 20-30s: Direct answer -> Reason/Effect -> Small detail. Answer the exact question first; do not turn a narrow question into a broad essay. PART2: 1:40-2:00: 1 minute prep with 6 keywords. Long-term chain: Background -> Difficulty -> Event -> Turning Point -> Result -> Reflection. Cover all cue-card bullets; do not memorize a full script. PART3: 45-60s: PEEL = Point -> Explanation -> Example/Effect -> Link. Teacher question-type buckets: listing, comparison, agree/disagree, solution/how, prediction. Cause/reason questions use the same Point + Why + Example logic. Software rule: When importing into Wordly, keep storyCluster / status / needsPersonalDetails. A generic question-bank sample must never overwrite a user-specific story.
