# 10月3日雅思听力：课程整理与训练规划

日期：2026年10月3日（北京时间）  
依据：上传的《103Lili雅思听力试听课纪要.md》。本文件为整理与训练建议，不是录音逐字稿。未提供完整题目与音频，课堂例题答案不作独立核验。

## 1. 今天这节课到底学了什么

**核心目标：提高审题效率，在录音中识别题目需要的信息，并检查它是否真正支持答案。**

课堂主要针对三类问题：审题时逐词翻译导致时间不足；选项都听到过却不能判断归属；定位词认识但录音里听不出来。这些是课程讨论的训练方向，不能仅凭纪要认定你已经存在每一种问题。

| 模块 | 老师重点 | 你要练到的具体动作 |
|---|---|---|
| 审题与定位 | 专有名词、数字、否定、比较等信息 | 每题先确定问什么，再勾1–2处关键短语；数字要连同对象一起看 |
| 语篇分层 | 新话题、并列、顺序、转折 | 听清哪一题开始、说的是谁、内容是主张还是例子 |
| 答案核验 | 未提及、主体不符、相反概念 | 为正确选项指出证据，为错误选项说明不匹配之处 |
| 同义替换 | 题干与录音不一定用相同词 | 将“题目表述—录音表述—共同含义”成对记录 |
| 词汇听辨 | 会读、会听、反应快 | 英文音频→理解含义→拼写；不能只看词表认词 |
| 错题重做 | 比较第一次与第二次表现 | 重听要验证是否能独立定位；用新题检查迁移，避免只记住答案 |

老师提出的课后要求：每天或隔天听写；提高词汇熟悉度；重做已做题并比较变化。纪要没有明确布置书面作业，也没有给出正式排课时间、总课时或费用。

## 2. 必须修正的几处课堂笔记

以下是对纪要文字的修正，不能据此断言老师在完整授课语境中说错。原纪要是二次整理，可能省略了前提。

| 纪要中的说法 | 可靠的使用方式 |
|---|---|
| 定位词按固定词性顺序严格选择 | 作为审题提示可以；最终由题目要比较的含义决定。动词、形容词也可能正是选项差异，如容易修复与难以修复 |
| 勾什么词就听什么词 | 听它对应的含义及同义替换，不能等原词逐字出现 |
| 首句没有转折或否定就是答案 | 首句只能是候选证据；必须确认回答题干，且没有后续修正 |
| 每句话对应一个选项，听到两句即可排除第三项 | 句子数量不能决定选项数量；同一句可能涉及多个选项，一个选项也可能跨句表达 |
| on the other hand 表转折，所以排除 | 它提示对照或另一面；后面的信息也可能正是答案。不能自动排除任一选项 |
| Part 1提问的最后一个名词常是答案 | 问句帮助定位；答案可能在问句、回答或更正中，仍须听完整问答并检查空格要求 |
| 数字必考；其余修饰成分都可忽略 | 数字是常见线索，但也可能是干扰信息。主体、时间、范围、程度、肯否等限制不能忽略 |
| range of、the number of、an amount of都表示很多 | a range of强调范围或多样性；a number of表示若干；the number of表示数量；an amount of表示一定量，均须结合上下文 |
| various of | 通常应写various +复数名词，如various methods；或a variety of methods |
| free、replace、reduce、beyond等均是“否定词” | 这些词不都含语法否定。free of可能表示没有；replace表示替换；reduce表示减少。先理解作用对象，再判断是否与选项相反 |
| hardly、seldom、neither、nor都属频率类 | hardly表示几乎不；seldom表示很少发生；neither/nor用于否定选择或连接否定成分，不是频率词 |

**统一原则：定位词帮助找到证据，完整语义决定答案。**

## 3. 做题时只执行这一套流程

### 听前：看清问题与差异

1. 看题干：问谁、问什么、限定哪个阶段或条件。
2. 填空题：核对字数限制，预测所需词性与信息类型；暂不猜最终答案。
3. 选择题：比较选项差异，例如历史更久、使用者更多、更容易修复，而非勾三个选项共有的pottery。
4. 勾1–2处关键短语；否定、比较、数量与范围另作简短标记。不要将“只勾两词”变成硬限制。

### 听中：定位后继续核验

1. 听到定位线索或同义表达，开始捕捉对应信息。
2. 判断主体、时间、范围是否与题干一致。
3. 注意but、however、actually、instead、no longer等可能带来的修正；不能只等这些词，修正也可能用其他表达。
4. 漏题时作标记，跟进下一题，避免连续丢失。

### 听后：答案必须有证据

1. 填空检查拼写、单复数、语法与字数限制。
2. 选择题指出支持正确选项的录音句，并说明其他选项为什么不匹配。
3. 正确但靠猜的题也要复盘。

## 4. 今天值得保留的词汇与表达

| 表达 | 准确含义 | 听辨或做题提醒 |
|---|---|---|
| impressions / marks | 印痕／痕迹 | 在特定陶艺语境中可能对应，不能把所有用法视为完全相同 |
| by examining the impressions on the clay | 通过检查黏土上的印痕 | 检查对象是印痕，clay交代载体 |
| begin / start | 开始 | 与到达、结束时间区分 |
| longer | 更长／更久 | 判断比较的是时间、长度还是其他对象 |
| more easily repaired | 更容易修复 | 必须同时理解修复与容易程度 |
| hardly / seldom | 几乎不／很少 | 不同于hard或sometimes |
| little / a little | 几乎没有／有一点 | 常与不可数名词搭配；a会改变含义 |
| neither…nor… | 既不……也不…… | 看清被否定的两个对象 |
| no longer / lack / unnecessary | 不再／缺乏／不必要 | 确认否定或缺少什么 |
| a range of / a variety of | 一系列／多种 | 重在范围、种类；不与“数量多”机械等同 |
| a number of / the number of | 若干／……的数量 | 二者含义不同 |
| plenty of / numerous | 大量／众多 | numerous通常修饰复数可数名词 |
| content / topic | 内容／主题 | 细节内容与整体话题不能混选 |
| a single sentence | 一句话 | 课堂例子中用于概括展示核心 |
| ties together the whole presentation | 串联整场展示 | 指组织关系，不只是更改某个细节 |

今晚从表中选择15–20项听辨，不必一次背完。每项按“听英文—口头说意思—写英文—核对”完成。容易混淆的短语需放回原句练习。

## 7. 错题本与每天的验收

| 日期／材料／题号 | 首次答案→正确答案 | 错因 | 录音证据／时间点 | 题干与录音的替换 | 延迟重做 |
|---|---|---|---|---|---|
| 待填写 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 |

错因统一使用：①不认识词；②认识但听不出；③听懂但反应慢或跟丢；④主体／时间／范围判断错；⑤转折或修正没跟上；⑥同义替换没识别；⑦拼写／语法／字数限制错误；⑧无证据猜测。可有多个原因，指定一个主要原因。

每天验收：

- 完成15–20项听辨，保留首次结果；次日再测错项。
- 完成一组新题，记录首次正确数与题量。
- 至少复盘3个错题或猜对题；若不足3题，补选正确题检验证据。
- 写出至少3组在实际练习中遇到的同义表达。
- 明确明天优先解决的一个错因。

执行参考：错词次日复测目标≥90%。这是内部训练目标，不是雅思分数换算。不要将重做正确率当成当前考试水平，也不要凭两套题的变化宣称稳定提分。
